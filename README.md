# Régie

Статические HTML-страницы для Régie — рабочего стола для организаторов мероприятий и ресторанов.

## Файлы

- `index.html` — главная страница (маркетинг, тарифы, контакты)
- `samples.html` — примеры страниц системы
- `workspace.html` — приватный рабочий инструмент (бриф, тайминг, бюджет, меню для Pro). Не привязан ссылками с главной страницы. Все данные клиента хранятся только в localStorage браузера, который открыл страницу — в самом файле и в репозитории данных нет.

## Публикация через GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.

После этого сайт будет доступен на `https://<username>.github.io/<repo-name>/`.
